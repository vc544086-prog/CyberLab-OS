# CyberLab OS: Project Overview

**CyberLab OS** is an advanced Dual-Architecture Operating Systems Engineering & Research Platform created by **Vishnu C (25BTRCL282)** at JAIN (Deemed-to-be University).

## Dual Architecture Philosophy
1. **CyberLab Linux (Distribution Layer)**: A customized Debian 12 Bookworm live system featuring a futuristic KDE Plasma desktop, custom Qt6 Network Center, System Monitor, and ByteRunner arcade engine.
2. **RustOS (Bare-Metal Kernel Layer)**: An independent 32-bit x86 freestanding operating system written in pure Rust (`no_std`), running in Ring 0 with custom GDT, IDT, 8259 PIC, PIT, and VGA text driver.
3. **Academic Research Experiment Lab**: Direct empirical evaluation of CPU scheduling trade-offs (**Fairness vs Throughput**) based on Vishnu C's academic paper.
