# CyberLab OS: Desktop Environment Specification

## Visual Identity
- **Color Palette**:
  - Deep Charcoal: `#0d0e15` (Window background)
  - Surface Charcoal: `#141622` (Panel and widget surface)
  - Cyber Cyan: `#00f0ff` (Primary highlights and telemetry)
  - Electric Purple: `#7928ca` (Accents, docks, gradients)
  - Text: `#e1e3ea` (High legibility modern font)
- **Distinct from Windows 11**:
  - Floating bottom dock (macOS-inspired ergonomics).
  - Slim top telemetry panel displaying real-time CPU, RAM, active virtual workspace, and date/time.
  - Four pre-configured virtual workspaces:
    1. **Research**: Dedicated to algorithm simulation and graphing.
    2. **Development**: C, C++, Rust compilation environments.
    3. **Networking**: Hardware diagnostics and Network Center.
    4. **System Monitoring**: Real-time process and thermal tracking.
