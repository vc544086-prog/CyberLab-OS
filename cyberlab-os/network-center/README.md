# CyberLab Network Center

A modular Qt6 & NetworkManager desktop application delivering comprehensive wireless and ethernet hardware diagnostics for the **CyberLab OS** distribution.

## Highlights
- **Not a Windows clone**: Custom dark-charcoal and electric-cyan cyberpunk UI.
- **VirtualBox Awareness**: Correctly identifies hypervisor virtual Ethernet devices without generating fake or hallucinatory Wi-Fi networks.
- **Secure Authentication**: Uses NetworkManager D-Bus / client layer with masked credentials rather than insecure shell parameters.
- **Live Bandwidth Telemetry**: Samples `/proc/net/dev` and routing tables for real-time traffic statistics.
